# 코칭 규칙

규칙마다 입력·조건·쿨다운·멘트 키를 적는다. 임계값 숫자는 `CoachingConfig`와 맞춘다.
숫자가 정해지지 않은 곳은 [미확인]. 정할 때 근거(테스트·자료)를 같이 적는다.

## 공통
- 주행 중(기어 D/R)에만 코칭. P면 멈추고 리포트
- 같은 규칙은 쿨다운 시간 안에 반복하지 않음: [미확인]초
- 한 번에 한 문장. 동시에 여러 개면 우선순위: [미확인]

## [실제] 규칙
### 1. 깜빡이 없이 핸들 크게 꺾음 ✅ 구현 (2026-11-13, `TurnSignalMissingRule`)
- 입력: 조향각, 방향지시등, 기어
- 조건: 기어 D + |조향각| ≥ 90° + 방향지시등 OFF, 이 상태가 0.8초 이상 계속
  - 90°: 핸들 1/4바퀴 (에뮬레이터 범위 ±540 기준). **초기값, 근거 [미확인]**
  - 0.8초: 순간 값·꺾은 직후 깜빡이 조작을 거르기 위한 대기. **초기값**
- 한 번의 꺾음(에피소드)에서는 한 번만 말함. 쿨다운 10초 (**초기값**). 쿨다운 중 시작된 꺾음은 늦게라도 말하지 않음
- 방향지시등·조향각을 아직 모르면(null) 말하지 않음
- 제외: 저속(주차·유턴)은 차속 미확보로 아직 못 거름 [미확인]
- 평가: 서비스가 200ms마다 최신 상태로 평가 (시간 조건 때문에 값 변화만으로는 부족)
- 테스트: `TurnSignalMissingRuleTest` 11개
- 멘트: `voice_turn_signal_first` "방향지시등을 먼저 켜 주세요."

### 2. 깜빡이 켠 채 계속 직진
- 입력: 방향지시등, 조향각
- 조건: 방향지시등 켜짐 + |조향각| < [미확인]° 상태가 [미확인]초 이상
- 멘트: "방향지시등이 켜져 있어요"

### 3. 회전 구간 전 깜빡이 예고
- 입력: 내비 TBT, 방향지시등 — TBT 이벤트 수신 가능 여부 [미확인]
- 멘트: "200미터 앞 우회전이에요, 깜빡이 먼저요"

### 4. 핸들 흔들림 (SteeringStabilityAnalyzer)
**직접 설계하는 부분.** Claude는 질문·힌트·리뷰·테스트만.
설계할 때 정해야 할 것:
- 몇 초 구간(윈도)을 볼 것인가
- "흔들림"을 무엇으로 셀 것인가 (좌우 방향 바뀐 횟수? 진폭?)
- 아주 작은 떨림(센서 노이즈)은 어떻게 무시할 것인가
- 진짜 회전(교차로·커브)은 어떻게 제외할 것인가
- 차속을 쓸 것인가 (차속 입력 가능 여부 [미확인])
- 멘트: "핸들이 흔들려요, 시선을 멀리 두세요"

### 5. 급제동
- 입력: 브레이크 페달 (+ 차속)
- 조건: 페달 값이 [미확인]초 안에 [미확인]% 이상 증가
- 멘트: "앞차와 거리를 여유 있게 두세요"

### 6. 주행 보조 해제
- 입력: 크루즈 상태 (DrivingMode)
- 조건: 활성 → 비활성 전환
- 멘트: "주행 보조가 해제됐어요, 직접 속도를 조절하세요"

### 7. 경고등 해설
- 입력: Telltales — 지원 경고등 목록(`TelltaleType`) [미확인]
- 조건: 경고등 새로 켜짐
- 멘트: 경고등별 (예: "타이어 공기압 경고예요, 가까운 곳에서 확인하세요")

## [시연] 규칙 (PerceptionSource 입력, 화면에 "시뮬레이션 데이터" 배지)
- 차선 물기: "오른쪽 차선에 가까워졌어요"
- 차선 변경 시 옆 차 근접 (+ 실제 깜빡이): "오른쪽 뒤에 차가 있어요, 조금 기다렸다 변경하세요"
- 실선 차선 변경 (+ 실제 깜빡이): "지금은 실선 구간이라 변경할 수 없어요"
- 고속도로 저속: 차속·도로 종류 입력 확보되면 [실제]로
