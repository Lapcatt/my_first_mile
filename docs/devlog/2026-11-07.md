### 에뮬레이터 이미지가 SDK Manager에 안 뜸
- 공식 가이드대로 SDK Update Site(`crp-arm64-sys-img.xml`)를 추가했지만 SDK Platforms 목록에 Pleos 이미지가 안 나타남
- sdkmanager는 deprecated, 새 Android CLI는 `system-images;android-34;pleos_car_emulator;arm64-v8a`를 "not found" 처리
- 해결: 서버 XML에서 zip 주소를 찾아 직접 받음
  1. `~/Downloads/crp_car_arm64_emulator.zip` 다운로드, sha1 `24d28eb2f18eba5e87c861a7eb2bdccebb049419` 일치 확인
  2. 디스크 여유 확인 (설치 전 27.5GB, 압축 해제 크기 18.6GB — system.img만 17GB)
  3. `~/Library/Android/sdk/system-images/android-34/pleos_car_emulator/`에 `unzip` (ditto 없이 성공)
  4. `crp_avd_out_arm64-v8a/` → `arm64-v8a/`로 이름 변경
  5. zip 안에 package.xml은 없고 source.properties·devices.xml·build.prop은 있어서 package.xml은 안 만듦

## 배운 것
- SDK 패키지 경로 `system-images;android-34;pleos_car_emulator;arm64-v8a`는 SDK 폴더 안 디렉터리 구조와 그대로 대응한다
- Android Studio는 패키지 정보를 package.xml(새 방식) 또는 source.properties(옛 방식)에서 읽는다
- zip 안 source.properties는 서버 XML과 내용이 다름 (Revision 1, Vendor 42dot, Tag 표시 "Automotive", RAM 8192MB) → Studio에서 "Pleos Connect v2.1.0 APIs"가 아니라 "Automotive"로 보일 수 있음
- AVD는 반드시 Cold boot. Quick boot면 VHAL(차량 신호 계층)이 꺼진다
- 에뮬레이터 버전 37.2.13 (이미지 요구 조건 24 이상)
- sdkmanager는 Android Studio 내장 JBR(`/Applications/Android Studio.app/Contents/jbr/Contents/Home`)로 실행
